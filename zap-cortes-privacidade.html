Política de Privacidade - Zap Cortes

Última atualização: 2026-10-05

O que é o Zap Cortes

O Zap Cortes é uma ferramenta pessoal, de uso individual, que roda no computador do próprio usuário. Ela prepara vídeos verticais curtos com legendas e, a pedido do usuário, envia o vídeo para a caixa de entrada (rascunhos) da conta do TikTok dele, para que ele revise e publique manualmente no TikTok. O Zap Cortes não tem servidor próprio, nem contas de usuário, nem anúncios.

Dados que tratamos

Ao conectar a conta do TikTok (Login Kit), o app recebe do TikTok: o identificador da conta (open_id), o nome de exibição e a foto de perfil, e os tokens de acesso autorizados pelo usuário. Esses dados ficam guardados somente no computador do usuário, em um arquivo local, e são usados apenas para mostrar qual conta está conectada e para enviar o vídeo que o usuário escolheu.

Os vídeos enviados ao TikTok são os que o usuário selecionou no app, no momento em que ele pede o envio. O app não coleta nem lê outros dados da conta do TikTok.

Compartilhamento

Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros. Os dados só trafegam entre o computador do usuário e o TikTok, nas chamadas autorizadas pelo usuário. A página de retorno do login (zap-cortes-retorno) é estática: apenas repassa o resultado da autorização ao app no computador do usuário e não grava nem registra nada.

Retenção e remoção

Os tokens ficam no computador do usuário até ele desconectar a conta no app ou apagar o arquivo local. O usuário também pode revogar o acesso a qualquer momento nas configurações de segurança da própria conta do TikTok.

Privacy Policy - Zap Cortes

Last updated: 2026-10-05

What Zap Cortes is

Zap Cortes is a personal, single-user tool that runs on the user's own computer. It prepares short vertical videos with captions and, when the user asks, sends the video to the inbox (drafts) of the user's own TikTok account so that the user can review it and publish it manually on TikTok. Zap Cortes has no server of its own, no user accounts and no ads.

Data we handle

When the user connects their TikTok account (Login Kit), the app receives from TikTok: the account identifier (open_id), the display name and profile picture, and the access tokens the user authorized. This data is stored only on the user's computer, in a local file, and is used only to show which account is connected and to send the video the user chose.

The videos sent to TikTok are the ones the user selected in the app, at the moment the user requests the upload. The app does not collect or read any other data from the TikTok account.

Sharing

We do not sell, rent or share personal data with third parties. Data only travels between the user's computer and TikTok, in calls authorized by the user. The login return page (zap-cortes-retorno) is static: it only hands the authorization result to the app on the user's computer and does not store or log anything.

Retention and removal

Tokens stay on the user's computer until the user disconnects the account in the app or deletes the local file. The user can also revoke access at any time in the security settings of their own TikTok account.
